# 鲜花消消乐 v1.1.1 🌸（补丁版）

> 修复 v1.1.0 发现的系统返回（侧滑手势）问题。功能与 v1.1.0 完全一致，可直接覆盖安装。

## 🐛 修复

- **关卡内使用侧滑返回 / 返回键不再直接退出游戏**，改为返回选关界面
- 修复前：Godot 默认在无人处理返回事件时自动退出应用
- 修复后，三个界面的返回行为如下：

| 界面 | 返回手势/返回键行为 |
|---|---|
| 游戏内 | → 返回**选关界面** |
| 开场宣传片 | → 跳过开场，进入选关 |
| 选关界面 | → 退出应用（保留 Android 首页退出惯例） |

## ✅ 验证

- 新增 `tests/smoke_back` 回归测试（返回导航路由断言）
- 真机验证：返回键 + 屏幕边缘侧滑手势双路径实测，游戏内返回 → 选关界面 ✅；选关界面返回 → 正常退出 ✅
- 53 项单元测试 + 7 套场景冒烟测试全绿

## 📦 安装

- 下载 `flowermatch3-1.1.1.apk`（Android 8.0+，arm64）
- **从 v1.1.0 / v1.0.0 升级：直接覆盖安装**（同一发布签名，存档与星级保留）
- 从 debug 测试版升级：请先卸载（签名不同）
