# 鲜花消消乐 v1.1.3 🌸（紧急修复：棋盘"空洞"导致卡住）

> 修复一个有障碍关卡才会出现的严重问题：**藤蔓 / 雪块把一列切成多段后，段内被消除的棋子不会被补充**，格子永久空着——棋盘越来越稀疏，玩家会看到"根本没有可消的花"而卡住。

## 🐛 根因（这次找到了真正的元凶）

| 环节 | 问题 |
|---|---|
| **重力填充只处理"列顶段"** | 藤蔓/雪块是"墙"，一列会被切成 2~3 段。旧的重力逻辑只会给**最上面那段**补充新棋子；**中间段与下方段**被消掉后永远留空 |
| **连锁后果** | 空洞不是外观问题：棋盘可用棋子越来越少 → 可交换的组合急剧减少 → 极易真的变成"无解"；加上空格视觉上像"缺了一块"，玩家很难看清还能消什么 |
| **第二处隐患** | 交换动画结束后若棋子已被销毁（连锁/特殊效果），旧代码会报错并中断，导致一次移动后**所有点击永久失效** |

## 🛠 修复内容（四层防线）

1. **分段重力**（根因修复）：每列按障碍切成若干段，**每段独立下落 + 独立补充**，段内再也不会留洞
2. **补洞兜底**：每次移动结算后自动检查棋盘，发现空洞立即补齐（并避免补出即时三连），日志可见 `[self-heal] 补洞 N 格`
3. **输入看门狗**：若因异常导致内部忙碌标记卡住，8 秒后自动复位并重新自检——**点击永远不会永久失效**
4. **防已销毁棋子**：交换过程中棋子被销毁时安全收尾（旧版会中断流程，造成上述输入死锁）

另：会持续输出 `[self-heal]` 诊断日志，便于以后排查。
