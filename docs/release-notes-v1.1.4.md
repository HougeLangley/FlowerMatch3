# 鲜花消消乐 v1.1.4 🌸（难度调优 + 智能提示）

> 本期两件大事：**把过难的关卡调到"够得着 3 星"**，以及**让"找不到可消的花"彻底消失**（自动提示）。

## 📉 难度调优（用实测数据说话）

用自动试玩（贪心 AI，每关采样 12~30 局）测出各关得分分布，再对齐门槛：

| 关卡 | 3★ 达成率（调优前 → 调优后） | 失败率（前 → 后） | 主要改动 |
|---|---|---|---|
| 第 2 关 藤蔓 | **0% → 47%** | **75% → 7%** | 藤蔓 6 根 → **4 根**（不再把棋盘切成 3 条封闭竖带）、步数 22 → **24**、目标 2000 → **1800** |
| 第 3 关 雪块 | 0% → 62% | 33% → 12% | 步数 24 → **26**、目标 3200 → **2400** |
| 第 4 关 心形 | 0% → 27% | 83% → 3% | 步数 28 → **30**、目标 4800 → **2300** |
| 第 5 关 终极 | 8% → 38% | 33% → 12% | 步数 28 → **30**、目标 6500 → **5200** |
| 第 1 关 热身 | 58% → 88% | 0% | 保持（引导关就该轻松） |

**为什么第 2 关特别难？** 原配置的 6 根藤蔓横竖连成两排，把棋盘切成三条互不相通的竖带——连锁与塌陷都无法跨墙，得分被硬生生压掉一半以上。这是关卡设计里最典型的"切碎棋盘"失误，已改为 4 根错位藤蔓，保留障碍教学又不伤乐趣。

## 💡 智能提示（同类游戏标准做法）

- **超过 6 秒**没找到可消的，自动高亮一组**真实可行**的交换（两颗棋子轻微脉动 + 一声轻提示音），每 4 秒重复一次直到玩家操作
- 提示与"死局判定"共用同一套规则函数（不会提示假的）；如果棋盘真的无解，直接走自动重排
- 这样"找不到可消的花"的情况从体验层面消失——不用玩家自己盯着棋盘找

## 🔍 死局问题复查（上次修复的后续验证）

- 用**压力测试**在 5 个关卡连续自动试玩 **120 局**，每一步都断言：**棋盘无空洞 + 必有可行步** → **零违例**
- 也就是说棋盘状态层面已经不会卡死；剩下的"无可消"体验问题由本次的**提示系统**兜住
