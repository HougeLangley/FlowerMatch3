# 鲜花消消乐 v1.1.0 🌸

> 这次更新的主题是——**让花园活起来**。

![花朵闲置动效](https://raw.githubusercontent.com/HougeLangley/FlowerMatch3/v1.1.0/docs/screenshots/anim_idle.gif)

从 v1.0.0 到 v1.1.0，棋盘上的花不再是静止的贴图：每一朵都有自己的小动作；声音从 5 个单调音效升级为一整套会随连锁"唱歌"的体系；五个关卡各自长出了不同的性格。

## 🌷 花朵有了生命

- **每种花不同律动**：玫瑰摇曳、向日葵呼吸、樱花飘浮、郁金香摆头、薰衣草轻飘、百合静谧，魔力花缓缓旋转、爆炸花心跳加速
- **花园波浪**：动效相位沿棋盘对角线错开，一眼望去像整片花田被微风拂过，而不是全场同步闪烁
- **与操作零冲突**：动效作用在花瓣精灵上，交换/消除/重力动画各走各的通道，快节奏操作也不会"打架"

![游戏画面](https://raw.githubusercontent.com/HougeLangley/FlowerMatch3/v1.1.0/docs/screenshots/shot_board.png)

## 🎵 音效全面重做（14 种，全部代码合成）

- **消除不再复读**：3 种音色变体随机轮换，每次消除都略有不同
- **连锁唱歌**：沿五声音阶（C D E G A）逐级升高，连得越多越好听
- **处处有反馈**：点选、交换、无效交换、特殊花生成、行列消除、爆炸、魔力花、雪块破碎……每个动作都有专属音效
- **多声部池**：连锁爆裂时多个音效叠加，不再互相打断
- **位置声场**：声音按格子位置左右分布——消除发生在左边，声音就从左边来
- 过关琶音收束、实时星级"叮"声、失败也是温柔的（不沮丧）

## 🔇 一键静音

分数栏左端的花盘按钮，一键全局静音（含所有音效），设置自动保存、重启保持。
——通勤、排队、办公室摸鱼友好。

|---|---|---|
| 第 1 关 | 全开放 6 色，热身 | 晴日花园 |
| 第 2 关 | **藤蔓**阻挡，学会绕行与借力 | 樱花飘落 |
| 第 3 关 | **雪块**开图，相邻消除破冰扩地 | 晴日花园 |

| 第 5 关 | 5 色更爽快 + 藤蔓雪块**双障碍** | 晴日花园 |

## 🎬 双主题无缝循环动态背景

MiniMax H3 生成的「晴日花园」「樱花飘落」两段循环视频背景（正放+倒放拼接成回文，无缝循环），按关卡主题自动切换。

## ⭐ 结算更带感

- 星星**逐颗弹跳点亮**（不再瞬间全亮）
- 实时星级跨过门槛时的一声清脆"叮"，由低到高
- 达标即结算？不——打到三星线才完美收官，否则玩满步数按最终分评星
