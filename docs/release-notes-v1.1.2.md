# 鲜花消消乐 v1.1.2 🌸（紧急修复）

> 修复「棋盘无可消内容时无法自救」的问题——有障碍的关卡可能卡死，本版本已彻底解决。

## 🐛 修复：死局（无可消除）时游戏不会自救

**现象**：在有障碍的关卡（藤蔓 / 雪块 / 双障碍）游玩时，棋盘可能出现"没有任何一组能消"的局面，此时无论怎么交换都是无效交换，游戏却没有任何反应，玩家被卡住。

**根因**：可行步检测（`has_possible_move`）没有把「障碍格」排除在外——它会尝试用**空格子**与棋子交换来寻找三连。障碍旁边的棋子在检测中被"虚拟交换"出一条三连，于是引擎误判"还有解"，从而**永远不会触发重排**。
（另外旧版在"存在魔力花"时会直接跳过检测，魔力花被障碍围死时同样会卡住。）

**修复**：
1. 可行步检测与**真实交换规则**完全对齐：
   - 障碍格 / 空格不可交换（不再产生幻觉解）
   - 魔力花与任意相邻棋子交换都有效（且被围死时正确判定为无解）
2. **自动重排**：确实无解时立即重排——**保留特殊花与障碍**，只重新着色其余棋子，并保证重排后
   - 没有自动三连（不会有意外连锁）
   - 一定有可行步（不会再卡）
3. **可见反馈**（借鉴同类游戏的做法，重排不再"静默发生"）：居中提示「无可消除，重新排列！」+ 音效 + 全盘花朵脉冲
4. **双保险触发**：除了每步结算后检查，**无效交换也会触发检查**——玩家乱点也能立刻脱困
