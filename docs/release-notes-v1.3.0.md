# 鲜花消消乐 v1.3.0 🌸✨（15 关 + 3D 风格棋盘）

> 本期主题：**棋盘站起来了**。新增 5 个 3D 风格关卡，棋盘会带着透视旋转归位；再配两段全新 AI 生成背景视频。

## 🧊 3D 风格棋盘（L11 起）

| 效果 | 说明 |
|---|---|
| **入场旋转** | 进关瞬间棋盘呈强透视斜视角，约 1.5 秒内**旋转归位**（三次缓动，带小幅回弹感） |
| **常态浮动** | 归位后仍有极轻微的双轴浮动（±3.7°/±1.6°，7.5 秒周期），棋盘"悬浮"着不僵硬 |
| **透视与厚度** | 单应矩阵投影（焦距 1.45，透视明显）+ 倾斜时轻微暗化 + 棋盘下方一层柔和投影，悬浮感十足 |
| **手感零妥协** | 触摸位置按**同一矩阵反算**回棋盘坐标——形变后点哪颗花就消哪颗花（真机手感与平面关完全一致） |

技术路线：棋盘渲染进 SubViewport → 全屏 TextureRect + 自写 `board_warp.gdshader`（单应矩阵形变）→ 输入代理按逆矩阵映射。**不引入 3D 渲染管线**，架构风险最小、性能开销可控。
